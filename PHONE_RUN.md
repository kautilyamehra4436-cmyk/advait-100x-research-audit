# Run Advait offline on Android (Termux or browser Python)
## Simplest
1. Open repository: https://github.com/kautilyamehra4436-cmyk/advait-100x-research-audit
2. Download files: `advait_engine.py`, `test_advait_engine.py`.
3. Use a Python environment such as Termux (from its official source) or a mobile Python IDE.
4. Run: `python test_advait_engine.py`
5. Demo: `python advait_engine.py`
No API keys required. This is an offline reference engine; it does not yet search for bounties, browse websites, submit work, or collect payments.
