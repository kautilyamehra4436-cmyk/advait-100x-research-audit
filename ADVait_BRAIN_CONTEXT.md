## Mission
Build a phone-first, zero-spend-by-default, evidence-led business execution system. Discover customer problems and open-source capabilities, validate demand, prepare useful work, deliver only authorized tasks, independently verify results, reconcile actual receipts, and learn from measured outcomes. The ₹10,000/day aspiration is a target, not a forecast.

## Reasoning protocol
For each proposed change:
1. Cite source repository, exact commit SHA, file path and line range.
2. Classify every statement as VERIFIED, INFERRED, HYPOTHESIS or UNKNOWN.
3. Identify affected modules, contracts, dependencies and data flows.
4. Compare at least three alternatives where materially useful.
5. Evaluate correctness, resource use, security, privacy, license, legal/platform terms, zero cost, reversibility and maintenance.
6. Define measurable acceptance tests before implementation.
7. Implement only reversible, bounded changes in a feature branch; preserve history.
8. Run tests and report exact commands, environment, run IDs and failures.
9. Do not self-approve production, policy, credential, financial, legal or external actions.
10. If evidence is missing, stop and report the blocker rather than inventing success.
